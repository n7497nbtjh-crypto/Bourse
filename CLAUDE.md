**https://enklair.com** (ancienne adresse repere-bourse.pages.dev redirigée ; réseaux : enklair_). Cloudflare Pages + Worker + D1, déployé par GitHub Actions (dépôt `n7497nbtjh-crypto/Bourse`).

## Façon de travailler (règles de Romain)
- **Économiser les crédits** : pas d'agents sauf demande explicite ; un sujet à la fois, le plus visible d'abord ; dire le coût avant une tâche longue ; lectures ciblées (`grep -n`, `sed -n`), jamais `site.css`, `composants.css` ni `app.js` en entier ; peu de captures.
- **Maquette avant de coder** tout changement visible important (fichier HTML dans `docs/maquettes/`, vrais chiffres), puis l'installer quand Romain dit ok.
- **Montrer le résultat** (capture), en quelques lignes, puis demander la suite.
- **Ne jamais dire « terminé » sans l'avoir testé.** Ne rien inventer (chiffres, sources, résultats). Un saut de chiffre n'est pas une erreur tant qu'une source ne le dit pas (Micron ×3,6 en 2026 était vrai).

## Ce que Romain veut
- Professionnel, inspirer confiance ; clair, visuel, pas de pavés, rien de « bricolé » ni qui fasse « IA ». « La jeunesse ne lit pas » : chiffre, jauge, pastille, verdict en deux mots ; le détail au clic. Ne rien retirer : rendre compréhensible.

## Interdits

- Jamais de concurrent nommé sur le site (6/11, Romain) ; comparer à des types de services.

## Gratuit / Premium (13/11 : une seule formule, 19 € par an, un seul paiement ; plus de mensuel)
Gratuit : 5 fiches complètes par jour (en-tête et 5 repères toujours ouverts ; favoris, Premium et robots non comptés : `f4Quota` de fiche4.js), 3 comparaisons par semaine, 5 « comparer à ses rivales » par semaine, actualité, ETF, agenda, dividendes, lexique. Premium : toutes les fiches, rang dans le secteur, classements, comparaisons sans limite. La navigation reste gratuite. **Le bouton de paiement n'est ouvert que si le serveur déclare un prix qui commence par « 19 »** (`premOuvert` d'app.js, variable `PRIX_UNIQUE` du Worker ; lien dans `STRIPE_LINK_UNIQUE`) : sinon la page affiche « bientôt ouvert » et un formulaire d'attente. Espace obligatoire avant de payer (/espace?payer=unique, puis `moi()` envoie vers Stripe avec `prefilled_email`) ; retour vers /premium/merci?session_id=… ; un code Premium du navigateur est rattaché au compte par `moi()`. Mon espace = le compte et les favoris. E-mails : Cloudflare Email Service (`sendMail` de compte.mjs), utilisé seulement pour renvoyer un code d'accès.

- **Ne jamais ajouter un commentaire `//` au milieu d'une ligne de code** : il a coupé du code cinq fois. Vérifier `node --check` et un vrai passage.
- Les robots fusionnent avec `-X theirs` : ne pas corriger un cache ou l'index pendant qu'un robot tourne. `data/index_reparer.mjs` remet les sociétés qu'un robot ancien aurait effacées.
- Limite Cloudflare Pages : 20 000 fichiers (17 128 le 5/11 ; FAQ en 256 paquets). Prochains candidats : `data/wd`, `data/actu/c`.
- En JavaScript `null <= 0` vaut vrai.
- **Feuilles Google** : une feuille fermée n'est recalculée qu'en partie (l'ouvrir dans un navigateur la recalcule) ; Google sert parfois une **copie ancienne** du CSV publié (7/11 : clôtures du 2/11 rangées au 6/11) : `cours_fetch.mjs` la détecte (`controle` dans cours.json, page État du site). La copie gardée par le Worker peut être partielle (sans devise ni capitalisation) : app.js complète avec le fichier du robot.
- `cf/site/data/etf.json` est regénéré depuis `data/etf_catalogue.json`.
- Historique des ETF (`data/etf_historique.mjs`, robot etf-hist.yml le samedi) : Amundi, iShares, SPDR et Invesco (Excel officiels, module xlsx), HSBC (fiche mensuelle) ; 1 092 ETF sur 1 174 le 7/11. - Le Cloudflare Web Analytics (s'il est activé) est bloqué par la CSP de `cf/src/pwa.mjs` : voulu, la page confidentialité promet aucune mesure d'audience tierce.
